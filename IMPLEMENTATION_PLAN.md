### speechmos API (confirmed by reading installed source)
- `run(sample, sr, model_type='dnsmos', return_df=True, verbose=False)`.
- For a **1-D ndarray**, returns a plain `dict` with keys `ovrl_mos`, `sig_mos`, `bak_mos`, `p808_mos`.
- `sr` must be exactly `16000` (module constant `SR`), else `ValueError`.
- ONNX sessions (`onnx_sess`, `p808_onnx_sess`) are created lazily in `DNSMOS.__init__` and cached in a
  **module-level global** `dnsmos`; the session is reused across calls. `ort.InferenceSession` is
  called with no `sess_options`, so it defaults to using all cores.
- Segments the padded signal into 9.01 s windows with a **1 s hop**, averages per-window MOS.
- `while len(audio) < int(9.01*fs): audio = np.append(audio, audio)` — a **zero-length** array
  loops forever. Guard before calling.

## 3. Phase 1 — Core scoring (`score`)

### 3.1 `config.py` constants (spec says module-level, tunable)
```
FRAME_MS = 25; HOP_MS = 10; TARGET_SR = 16000
NOISE_PERCENTILE = 10; SPEECH_PERCENTILE = 95
SILENCE_DROP_DB = 35
CLIP_ABS_THRESHOLD = 0.999
BANDWIDTH_DROP_DB = 60; BANDWIDTH_SMOOTH_BINS = 5
EPS = 1e-10
DNSMOS_SR = 16000
CHUNKSIZE = 8; FLUSH_EVERY = 500
```

### 3.2 `naming.py`
- Regex exactly: `^(?P<reciter>.+?)_(?P<kbps>\d+)kbps_(?P<surah>\d{3})(?P<ayah>\d{3})\.mp3$`
  (case-sensitive, `.mp3` only).
- `parse_name(name) -> (fields | None)`; non-matching → `reciter="UNKNOWN"`, `kbps/surah/ayah` empty.
- Recursive scan of `--data` with `rglob("*.mp3")`; collect non-matching (count + first 20 names),
  print distinct reciter keys + counts after parsing.
- `read_refs(path)`: file → `.csv` (column `filename`) or plain text (one basename/line); directory
  → recursive `*.mp3` basenames. Warn if a subfolder mixes reciters. Folder names are ignored.

### 3.3 `audio_io.py`
- `decode(path) -> (mono_float32_native, sr)`:
  1. `soundfile.read(path, dtype="float32", always_2d=True)` → `(n, ch)`, downmix `mean(axis=1)`;
     reject empty/NaN.
  2. On failure, if `ffmpeg` on PATH: `ffmpeg -v error -i <path> -f f32le -ac 1 -` with a known
     sample rate via `-ar`? **Careful:** we need the native rate for `bandwidth_hz`. Use
     `ffprobe`/`ffmpeg` to obtain `sample_rate` first, then decode at native rate, else parse
     `-vn -f wav` header. Implementation: run `ffmpeg -v error -i <path> -map a:0 -f f32le -ac 1 -`
     and determine rate via `ffprobe -v error -select_streams a:0 -show_entries stream=sample_rate`.
     If `ffprobe` absent, decode with ffmpeg into a temp WAV and let soundfile read it (which
     yields native sr).
  3. Both fail → raise `DecodeError(str)`.
- `resample_to_16k(mono, sr)` via `scipy.signal.resample_poly` with `g=gcd(16000,sr)`,
  `up=16000//g`, `down=sr//g`; skip if already 16000.
- `clamp(x)` → `np.clip(x, -1.0, 1.0).astype(np.float32)` applied to the 16 kHz signal after
  resampling (DNSMOS raises otherwise); also keep a clamped native copy for `clipping_ratio`
  (computed pre-clamp).

### 3.4 `metrics.py`
Frame analysis on the **16 kHz** mono signal — frame length `round(25ms*16000)=400`, hop
`round(10ms*16000)=160`, via `librosa.util.frame` (or `numpy.lib.stride_tricks.sliding_window_view`)
with `center=False`:
- `rms = sqrt(mean(frame**2))`; `db = 20*log10(rms + EPS)`.
- `noise_floor_db = percentile(db, 10)`, `speech_db = percentile(db, 95)`,
  `snr_est_db = speech_db - noise_floor_db`, `silence_ratio = mean(db < speech_db - 35)`.
- `clipping_ratio` on the **native-rate, pre-resample, pre-clamp** mono:
  `mean(abs(x) >= 0.999)`.
- `bandwidth_hz` on **native-rate** mono:
  `f, Pxx = scipy.signal.welch(x, fs=sr, nperseg=min(4096, len(x)))`;
  `Pdb = 10*log10(Pxx + EPS)`; light smooth with a length-`BANDWIDTH_SMOOTH_BINS` moving average
  along frequency; `peak = max(smoothed)`; scan **from the top frequency down** to the first bin
  with `smoothed >= peak - 60`; return that `f` (0.0 if none). Captures band-limited/upsampled
  old recordings.
- All constants from `config.py`; functions pure and unit-testable.

### 3.5 `dnsmos_wrap.py`
- `run_dnsmos(x16) -> dict | None`: guard `len(x16) == 0` (avoid speechmos' infinite append
  loop); ensure float32, 1-D, finite; call `speechmos.dnsmos.run(x16, 16000)`; return dict or
  `None` + error string.
- **Thread limiting:** onnxruntime's `InferenceSession` is called inside speechmos with default
  options (all cores). In each worker, *before the first DNSMOS call*, monkeypatch the module
  attribute:
  ```python
  import onnxruntime as ort
  _orig = ort.InferenceSession
  def _limited(*a, **kw):
      so = kw.get("sess_options") or ort.SessionOptions()
      so.intra_op_num_threads = 1
      so.inter_op_num_threads = 1
      kw["sess_options"] = so
      return _orig(*a, **kw)
  ort.InferenceSession = _limited
  ```
  `speechmos` looks up `ort.InferenceSession` at call time, so the patch takes effect. Also set
  `os.environ["OMP_NUM_THREADS"]="1"` early. This prevents CPU oversubscription with
  `--workers 7`.
- Worker `initializer` does the patch + a tiny warm-up `run(np.zeros(16000... )? no — need >=
  9.01 s)`: warm up with a short sine of `int(9.01*16000)` samples so the session loads once per
  process, not on the first real clip.

### 3.6 `score.py`
- `score_one(path, data_root) -> dict` (never raises):
  1. `decode_ok=True` try decode; compute identity fields, `duration_s`, `native_sr`,
     `actual_kbps = path.stat().st_size*8/duration_s/1000`.
  2. Compute classical metrics; compute DNSMOS on the 16 kHz clamp.
  3. Any exception → populate what we have, `decode_ok=False` (decode failure) or keep
     `decode_ok=True` with metric `NaN` + `error` (metric failure); return row.
- Row columns, in order (spec §5.2):
  `filename, path, reciter, kbps_label, surah, ayah, decode_ok, error, duration_s, native_sr,
   actual_kbps, ovrl_mos, sig_mos, bak_mos, p808_mos, noise_floor_db, speech_db, snr_est_db,
   silence_ratio, clipping_ratio, bandwidth_hz`.
- Orchestration: `multiprocessing.Pool(workers, initializer=_worker_init)` with
  `imap_unordered(..., chunksize=8)`; `tqdm` bar on stderr; a writer thread/main loop appends rows
  and flushes every 500. `workers = max(1, cpu_count()-1)` unless `--workers`.
- `--resume`: if `--out` exists, read its `filename` column into a skip-set; open in append mode
  (write header only when creating). New row count + skipped count reported.
- `--log` default `score.log` next to `--out`; use `logging` to file + stderr. Log start params,
  progress counters, per-file average, total wall time.
- **Benchmark/ETA:** before the full run, score the first 20 files through a short-lived Pool,
  report elapsed, per-file average, projected ETA, and any decode failures (handoff step 2). The
  20 are then recomputed in the real run (negligible) unless they are part of `--resume`.
- Cross-platform: `main()` guarded by `if __name__ == "__main__"`; no `fork` assumptions; the
  Pool initializer carries all state (imports of speechmos happen lazily in the worker).

### Phase 1 verification (spec §11)
- (1) `--workers 4` on 20 real dataset files → CSV with every column populated.
- (2) Zero-byte / truncated MP3 → `decode_ok=False`, run continues.
- (3) `--resume` after interrupt → same final row count as uninterrupted (test on the 20-file
  subset, then trust logic for the full run).
- (4) synthetic metrics tests (see §6).
- (9) runs headless, no display/audio device.

## 4. Phase 2 — `calibrate`

### 4.1 Metric table (spec §6.1)
| Metric | Direction | Floor |
|---|---|---|
| `ovrl_mos` | higher | 0.05 |
| `sig_mos` | higher | 0.05 |
| `bak_mos` | higher | 0.05 |
| `snr_est_db` | higher | 1.0 |
| `bandwidth_hz` | higher | 250 |
| `noise_floor_db` | lower | 1.0 |

### 4.2 Algorithm
1. Load `scores.csv`; coerce numerics; booleans from strings.
2. Resolve the 9 references by basename against the table. **Fail** naming any missing file.
   Each reference's reciter comes from its parsed filename (not the refs folder).
3. For each reciter present in refs:
   - `ref_values[metric]` = metric values on the 3 reference rows.
   - `iqr = q75 - q25` over **all decode_ok dataset rows of that reciter** (drop NaN).
   - `margin = max(floor, k*iqr)`, `k` default 0.25, overridden by `--k-reciter NAME=VAL`.
   - higher: `threshold = min(ref_values) - margin`, rule `value >= threshold`.
   - lower: `threshold = max(ref_values) + margin`, rule `value <= threshold`.
4. Global hard gates (reference-independent, overridable by editing JSON):
   `decode_ok == True`, `3 <= duration_s <= 150`, `speech_db >= -45`, `clipping_ratio <= 0.001`.

### 4.3 `thresholds.json` schema
```json
{
  "k_default": 0.25,
  "k_effective": {"Abdul_Basit_Murattal": 0.25, "Hudhaify": 0.25, "Husary": 0.25},
  "global": {
    "decode_ok": true,
    "duration_s_min": 3, "duration_s_max": 150,
    "speech_db_min": -45, "clipping_ratio_max": 0.001
  },
  "reciters": {
    "Husary": {
      "n_reference_files": 3,
      "reference_files": ["Husary_128kbps_008016.mp3", "..."],
      "metrics": {
        "ovrl_mos": {"direction":"higher","threshold":3.10,"ref_values":[...],
                     "iqr":0.71,"k":0.25,"margin":0.18},
        "noise_floor_db": {"direction":"lower","threshold":-48.2,"ref_values":[...],
                           "iqr":3.4,"k":0.25,"margin":1.0}
      }
    }
  }
}
```

### 4.4 Console output (spec §6.4) & warnings (§6.5)
Per reciter, per metric: 3 reference values, dataset median, threshold, and fraction of that
reciter's files passing **that single metric**; plus fraction passing everything. Warnings:
- any reference failing its own reciter's thresholds (bug indicator);
- any reciter with < 3 references;
- overall pass rate < 10% or > 95%.

Takes seconds — no rescoring. (acceptance #7)

## 5. Phase 3 — `plot`

`matplotlib.use("Agg")` before pyplot import. Per reciter a PNG with a 2×2 grid of histograms:
`ovrl_mos`, `bak_mos`, `noise_floor_db`, `bandwidth_hz`; reference values as vertical lines;
thresholds drawn when `--thresholds` given. Also `plots/summary.csv` with per-reciter
median/p10/p90 for each metric. Headless (acceptance #9).

## 6. Phase 4 — `review`

For each reciter (rank by `ovrl_mos` desc):
1. `above/`: `--n` (default 5) files with the smallest `ovrl_mos` that is `>= ovrl threshold`.
2. `below/`: `n` files with the largest `ovrl_mos` `< threshold`.
3. `random_rejects/`: `n` files sampled (fixed seed 42) from rows failing any check.
4. Copy with prefix `NN_ovrlX.XX_<basename>.mp3` (position within group).
5. `review/<reciter>/review.csv`: every copied file, its metrics, group, and the `;`-joined
   checks it failed.
6. `review/README.md`: folder layout + what to listen for in each group.
7. `--zip` → `review.zip` of the `review/` folder (only selected clips + CSV/README, ~45 files).
   Print zip path and size. **Then stop and wait for the user's per-reciter listening verdict**
   before touching `--k` (handoff step 4).

## 7. Phase 5 — `filter`

Evaluate **global gates first**, then the file's reciter metric thresholds. `reciter=="UNKNOWN"`
→ reject reason `unknown_reciter`. Reject rows collect **all** failed checks, `;`-separated, each
formatted against its direction (e.g. `bak_mos<2.91;noise_floor_db>-48.2;clipping_ratio>0.001`).
Writes to `--out-dir`:
- `keep.csv` (all score columns, kept rows);
- `reject.csv` (+ `fail_reason`);
- `summary.md` (per-reciter total/kept/rejected, top fail reasons, thresholds used);
- `keep_list.txt` (dataset-relative paths, one per line, `rsync --files-from` / gcloud-loop ready);
- optional `--copy-to DIR` copies kept files preserving basenames.

Invariant checked before writing: `len(keep)+len(reject) == len(scores)`, and every reject has a
non-empty `fail_reason` (acceptance #6). Re-runs with a different `--k` are seconds (acceptance #7).

## 10. Execution sequence & time budget

1. **Setup** — download 5.48 GiB (~minutes on GCS), verify, extract refs, install deps. *(handoff 1)*
2. **Implement** package + tests; run unit tests. 
3. **Smoke** 20 files (`--workers 4`), report ETA + decode failures. *(handoff 2)*
4. **Full `score`** to `scores.csv` — run under `nohup` with `score.log`, `--resume` safe. This is
   the long pole; estimate from the 20-file benchmark × 13,501.
5. **`calibrate`** → `thresholds.json`; print threshold table; **`plot`**. **Stop and wait.**
   *(handoff 3)*
6. **`review --zip`**; hand user the zip path/size; **stop and wait for verdict.** *(handoff 4)*
7. Adjust `--k` (global or per reciter) → re-`calibrate` → re-`review` as needed (no rescoring).
8. **`filter`** → `results/{keep.csv,reject.csv,summary.md,keep_list.txt}`. *(handoff 5)*

## 11. Risks & mitigations

| Risk | Mitigation |
|---|---|
| DNSMOS CPU-heavy on 13.5k clips | single-thread ONNX per worker (patch), 7 workers, benchmark→ETA, `nohup`+`--resume`, flush every 500 |
| speechmos infinite loop on empty decode | explicit `len(x16)==0` guard |
| `bandwidth_hz` fragile on very short clips | `nperseg=min(4096,len)`, clamp to [0, sr/2], tolerate no bin past −60 dB |
| `actual_kbps`/NaN metric comparisons | drop NaN when computing IQR/medians; NaN fails a metric in `filter` |
| MP3 decode differences | soundfile first (verified), ffmpeg fallback, `decode_ok=False` row on total failure |
| Reference basename typo | fail fast before scoring (Phase 0.5) and again in `calibrate` |
| CPU oversubscription | `OMP_NUM_THREADS=1` + `intra/inter_op_num_threads=1` |
| Cost of rescoring after choosing `k` | thresholds/plots/review/filter read `scores.csv` only |

## 12. Open items (decide during implementation, not blocking)
- Whether to add `joblib`/`concurrent.futures` — **no**; stdlib `multiprocessing.Pool` per spec.
- SQUIM (`--squim`) — **deferred**, only if review shows DNSMOS insufficient (spec §12).
- Exact `nperseg` / smoothing window for `bandwidth_hz` — start with the values above, tune after
